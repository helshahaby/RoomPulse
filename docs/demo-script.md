# 3-minute demo script

| Time | Scene | Action / line |
|---|---|---|
| 0:00 | 1 · Problem | Landing page. "Wearables need charging, fit and compliance — the people who most need monitoring often don't wear them." |
| 0:20 | 2 · Live | Monitor → Start. Sit still, even front lighting, ~60 cm. Show face box, forehead/cheek ROIs, FPS and latency. |
| 0:40 | 3 · rPPG | After ~15 s HR appears (only if TrustScore allows). Open Signals: raw RGB, POS vs CHROM, PSD peak, SNR. Switch POS ↔ CHROM. |
| 1:10 | 4 · Respiration | Move camera back so shoulders are in the dashed box; wait 20–30 s. If unavailable, say so — that's the point. |
| 1:35 | 5 · Movement | Turn head side to side. Motion sub-score drops. |
| 1:50 | 6 · TrustScore | State goes RED, number disappears, reason reads "excessive head movement…". Hold a printed photo to the camera → RED "no pulsatile skin signal". |
| 2:20 | 7 · Validation | Validation Lab. Show real UBFC results **only if you ran them beforehand**; otherwise show the empty state and explain why no numbers are shown. |
| 2:45 | 8 · Close | Impact (independent living, beds, wards) + limitations: not a medical device, accuracy on diverse skin tones unvalidated, respiration experimental. |

Rule: never narrate a number that isn't on screen from a real measurement.
